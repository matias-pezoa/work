Desconectado

Las credenciales no se guardan ni se suben al repositorio: se piden en pantalla cada vez (ver Anexo MQTT del curso). "Conectar por USB" lee directo del cable del ESP32 (Chrome o Edge, con el Monitor Serie de Arduino IDE cerrado). El instrumento ya emite la inclinación en los dos ejes con signo (X e Y, −90 a 90): acá se usa el rango completo del movimiento, no solo su magnitud.

Sin conectar (simulación)

Sin API key el sistema corre en modo simulación: muestra la cámara cruda y el prompt que se enviaría a Decart según los sensores, sin transformar la imagen. Con key conectada, el prompt se actualiza en vivo (máx. 1 cada 1,8 s) a partir del estado afectivo. El SDK se carga por CDN y nunca se probó de punta a punta — si la conexión falla, el error aparece en el registro y el sistema vuelve solo a simulación.
